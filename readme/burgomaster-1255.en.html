About the project

Hello there! My name is Anton Gladyshev, and I'm the author of this project.
The homepage of the project is https://github.com/Areso/1255-burgomaster .
This pet-project is dedicated to create a playable game, written in vanilla JavaScript, without even using jQuery and modern whistlers and jugglers, such as JS frameworks, TS->JS compilators, Node.js, web servers and so on.
Thus, to play the game, you need only a modern browser. To edit the game, you need only a text editor and imagination.
The project is oriented to be compact (in terms of the source code and the resources), blazing fast to download, fast enough to run even on aging devices

It runs well even on low-powered tablets and phones, let alone old PCs and laptops.

It heavily uses JS technologies as HTML5.Canvas, EcmaScript5 localStorage, JSON.parse() , and so on. So it requires a somewhat modern browser, with ES5/ES6 standarts support.

Minimum System Requirements

Browsers: any modern browser, but the game tested only on Firefox and Google Chrome

1024MB RAM

800MHz 1 Core CPU

5MB of data plan to download the game itself, analytics, and chat.
And some traffic will be used with in-game chat and usage statistics, though the game will work perfectly even if a connection is lost after the download is complete.
You also may download the game, to run it in offline (check options offline game).

This is a single-player game. There is built-in chat but it is not currently available to chat in.

Also, the game now has global goals, which are usually activated for a limited time.

In those events, all players can work together to achieve a high global goal, and in case of the achievement, they all got a reward, according to their pledge in the achievement.

The game itself is about building a city. You start with a set amount of gold and a few citizens.

This is an IDLE game, which means, every minute your city will spawn new citizens who will pay taxes to you.

You can construct as well as upgrade buildings, but upgrading existing ones will require more gold each time .

As of now, constructing building does not require time, only resources.

Straight management, which means, you need place management by clicking here and there and you will get what you clicked.
What game offers now:

13 buildings to build of 10 types

maps to explore (HoMM3-like)

autocampaigns (Fallout Shelter-like)

a hero managemenet

troops managemenet

artifacts to collect

executing people or placing festivals

University with a tech tree

random events: stealings from the treasury, fires and plagues

time-limited events: Halloween, New Year

two decoration themes: Summer and Winter

a record table

You will explore wild territories near your city.

Regarding your choices, you could get a boost in taxes, birthrate, happiness and so on.

The game could become a clicker game if you build the Gallows, and like to execute your citizens.

This game created and new features right now in development inspired by Travian, Townsmen, Stronghold and Stronghold Crusaders, HoMM (Heroes of Might and Magic), Lord of Realm, Anno series.

You can export and import save to transfer your progress between different browsers and PCs.
