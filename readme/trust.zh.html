第 1 步) Fork 或下载这个仓库
（如果你打算 fork，请确保把 你的 仓库放在名为 gh-pages 的分支上，这样 GitHub 才能自动为它生成网页！）

第 2 步) 翻译以下文件：

index.html —— 标题与社交分享文案（几个词）
words.html —— 互动内容的所有文本（约 3,300 词）
（可选）notes/index.html —— 脚注（约 1,100 词）
（可选）peeps/index.html —— 完整致谢名单（几个词）

第 3 步) 记得测试你的译文！你可以使用 http-server 或 MAMP 在本地进行测试。

第 4 步) 给我发邮件，附上你 fork 的仓库／翻译后文件的链接，收件地址为 N {{at}} NCASE {{dot}} ME。这里可能有些地方需要修修补补！（另外，如果你遇到任何问题，也请给我发邮件！我接下来几周都不在，回复可能会比较慢）

第 5 步) 等我忙完／闲下来，真正把你翻译的版本从英文主版本链接出去

第 6 步) 庆祝吧！🎉
