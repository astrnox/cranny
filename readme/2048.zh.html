2048 · 玩法索引

一个 2048 的改版集合：经典原样保留，旁边还印着六种新走法——倾斜重力的星球、蜂窝六边形、量子叠加、整除合成、斐波那契数列，以及一盘人机竞速。全部模式在手机、平板、电脑上均可直接触摸/滑动操作。

七种玩法

№ 玩法 页面 一句话规则
00 经典 game.html 方向键滑动，相同数字相撞合成，合出 2048
01 星球引力 game_gravity.html 你不推，你倾斜：转动星体让重力替你坠
02 蜂窝六边形 game_hex.html 六边形棋盘、六个方向滑动，在蜂窝里合体
03 人机对抗 game_ai.html 双棋盘人机竞速，谁先合成 2048 谁赢
04 量子叠加 game_quantum.html 叠加态瓦片：相干增强合二为一，或干涉相消湮灭
05 整除合成 game_dive.html 瓦片与约数合体相加，合成新数会解锁更多质数
06 斐波那契 game_fib.html 数字不是 2 的幂：首尾相接的斐波那契数才能合体

经典模式同时内置 限时挑战（1 分钟）、无尽模式、每日难题、别造 128、反转 2048、限步挑战（60 步内冲高分）与 障碍格（3 个不可通行格子），可通过游戏页内的模式切换或 ?mode=endless 等参数进入。

操作方式

  • 经典 / 蜂窝六边形 / AI 对抗 / 量子 / 整除 / 斐波那契：方向键 / WASD，手机上直接滑动。
  • 星球引力：←→ 或左右拖动转动星体，Space 或轻点让瓦片坠落合体。
  • 所有玩法均支持触摸滑动。系统开启「减弱动态效果」时，仅装饰动画被缩短，棋盘瓦片的滑动/合体反馈依然保留。

本地运行

任意静态服务器即可：

cd 2048
python3 -m http.server 8000
# 打开 http://localhost:8000/

设计说明

全站采用「暖陶 Warm Clay」视觉：暖奶油纸底、陶土棋盘与赤陶强调色，保留经典 2048 的米色灵魂。每个心动玩法以独立页面 + 独立样式呈现，改动彼此隔离，不互相污染。
