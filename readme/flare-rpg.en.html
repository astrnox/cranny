Flare: Empyrean Campaign

Flare: Empyrean Campaign is a single-player 2D action RPG with fast-paced action and a dark fantasy style.

It is built on the FLARE engine (Free/Libre Action Roleplaying Engine). Its repo is at https://github.com/flareteam/flare-engine

FLARE uses simple file formats (INI style config files) for most of the game data, allowing anyone to easily modify game contents. Open formats are preferred (png, ogg). Maps are edited using Tiled.

For best results, please use the latest version of the FLARE engine with the game data in this repository. Using an older version of the engine could result in some game elements not working correctly.

Flare screenshot

The flare-game content contains depictions of violence, blood, and mild gore.

Getting Started

The easiest way to play Flare: Empyrean Campaign is to get one of the engine + game bundles from our Downloads page. Flatpak users can also find it on Flathub.

Alternatively, you can build Flare from source and manually install the mods. See flare-engine's INSTALL.engine.md for details on building the engine.

Once you've built the engine, run it once so that the config and user data directories can be created.

After that, you'll need to copy the mods to to your user mod directory. Here are the locations for common platforms. For complete details, see flare-engine's README.engine.md:

  • Windows: %APPDATA%\flare\userdata\mods\
  • Linux: ~/.local/share/flare/mods/

The following mods should be copied:

flare-engine/mods/default

flare-game/mods/fantasycore

flare-game/mods/empyrean_campaign

Launch Flare and go to the Configuration menu. Go to the Mods tab and enable the fantasycore and empyrean_campaign mods.

Save Files

Save files are stored in saves/empyrean/ inside the user data folder. The location of you user data folder can be found in flare-engine's README.engine.md.

Packaging and Distributing

If you are packaging Flare Game for release (e.g. on an operating system's software repo), we suggest creating two packages.

  • flare-engine the package that contains the single engine reused by several games
  • flare-game, a package that requires flare-engine that only contains this game data

When distributing flare-game you may elect to omit these folders which are not used at runtime.

  • art\_src contains the raw files (e.g. Blender files) used to generate Flare's art.
  • tiled contains the Tiled-native map files used to export Flare's maps
